# Travel Compensatory Time Calculator

## Purpose
Browser-based tool for documenting and calculating travel compensatory time.

## How to run
Download the repository, extract it, and open `index.html` in a current web browser.

## Files
- `index.html` — page structure and user interface
- `css/styles.css` — formatting and print styles
- `js/app.js` — calculator behavior and logic

## Testing
Use fictional test data. Do not store real traveler, itinerary, or employee data in the repository.

## Known limitations
- PDF import may require an available PDF library.
- Calculation results require user validation against applicable policy and local procedures.
